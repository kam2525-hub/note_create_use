# YUGIRI MASTER 3D 全国ランキング（Google スプレッドシート連携）セットアップ手順

`games/day13-yugiri-3d/index.html` はデフォルトではブラウザ内ローカル保存（`localStorage`）で自己ベストランキングを表示します。
以下の 5 ステップで Google Apps Script (GAS) を接続すると、**全プレイヤー共有の全国湯切りランキング（残湯 mL 少ない順 → 麺流出少ない順）**が有効になります。

## 手順

1. 新しい **Google スプレッドシート** を作成します（シート名は自動で `yugiri_ranking` が作成されます）。
2. メニューの **「拡張機能」→「Apps Script」** を開きます。
3. エディタの初期コードを消し、同フォルダの [`gas_ranking.gs`](./gas_ranking.gs) の中身をすべて貼り付けて保存します。
4. 右上の **「デプロイ」→「新しいデプロイ」** を押し、種類で **「ウェブアプリ」** を選択します：
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員`
   - 承認画面が出たら許可してデプロイします。
5. 発行されたウェブアプリ URL（`https://script.google.com/macros/s/....../exec`）をコピーし、以下のいずれかに設定します：
   - **全ユーザーに自動共有したい場合**：`games/day13-yugiri-3d/index.html` 内の `const GAS_ENDPOINT = '';` に URL を貼り付けて GitHub Pages にプッシュ。
   - **手元でテストしたい場合**：ゲーム内「🏆 ランキング」モーダル下部の「⚙ スプレッドシート連携設定」に URL を貼り付けて保存。
