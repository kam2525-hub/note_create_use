# WARIBASHI MASTER 3D — スプレッドシート全国ランキング連携ガイド

約2分で、Google スプレッドシートをデータベースにした **無料の全国ランキング** を有効化できます。

## 手順

1. **Google スプレッドシートを新規作成**します（シート名は自動で `waribashi_ranking` が作られます）。
2. スプレッドシートのメニューから **「拡張機能」→「Apps Script」** を開きます。
3. エディタの中身をすべて消して、同じフォルダの [`gas_ranking.gs`](gas_ranking.gs) の内容をコピペして保存（`Ctrl+S`）します。
4. 右上の **「デプロイ」→「新しいデプロイ」** をクリックし、種類で **「ウェブアプリ」** を選びます。
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員`
   （「承認」画面が出たら「詳細」→「安全ではないページに移動」→「許可」）
5. 表示された **ウェブアプリ URL**（`https://script.google.com/macros/s/.../exec`）をコピーします。
6. 以下どちらかを設定します：
   - **全員に公開する場合**：[`index.html`](index.html) 内の `const GAS_ENDPOINT = '';` に貼り付けて GitHub へ push
   - **まず動作確認する場合**：ゲーム内の「🏆 ランキング」モーダル下部にある「⚙ スプレッドシート連携設定」にURLを貼り付けて保存

## 順位ルール
1. **50.00% からの誤差（`±0.00%`）が小さい順**
2. 同率の場合は **高難易度（神域【極】→ 初級）優先**
3. さらに同率なら **⚡ JUST節見切り回数 → 残り時間（速さ）** の順
