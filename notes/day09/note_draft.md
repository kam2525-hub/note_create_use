## 脳汁ポイント＆ゲーム仕様

1. **🔫 6段階リアルタイム武器進化（多パーツ3Dガンモデル）**：
   敵を撃破するほど進化ゲージが溜まり、**`LV.1 MK-9 TACTICAL`** → **`LV.2 DUAL STRIKER（左右二丁拳銃）`** → **`LV.3 M870 SHOTGUN（8発散弾）`** → **`LV.4 VECTOR X-99（超高速SMG）`** → **`LV.5 M134 VULCAN（6銃身回転ガトリング）`** → **`LV.6 HYPER RAIL-CANNON（極太貫通ビーム＋自動追尾ミサイル）`** へと銃モデルごと変貌！
2. **💥 連鎖爆破（CHAIN BLAST）＆ 3D装甲粉砕**：
   戦場の赤い燃料コアを撃ち抜くと白熱球＋2重衝撃波リング＋飛び散る3D装甲破片で周囲の敵を一網打尽！さらに迫り来る敵ミサイルを撃ち落とす **`MISSILE INTERCEPT!!`** や紙一重の **`JUST DODGE!!`** でスローカウンターも決まります。
3. **🤖 本格3D敵兵士＆巨大ボス『TITAN-IX OMEGA』部位破壊**：
   多関節サイバー突撃兵・重装甲メック・双発ロータードローンを蹴散らすと、全高7m級の巨大戦闘メック **『TITAN-IX OMEGA』** が出現！両肩の6連ミサイルポッドを部位破壊してから胸部プラズマコアを撃ち抜けば大爆発撃破＆**3択サイバーMOD覚醒**！
4. **📱 シンプル操作 ＆ 縦画面・横画面フル対応**：
   移動はダイナミックな自動前進！操作は「画面をなぞって照準＆連射」＋「`DODGE` 回避」＋「`OVERDRIVE` 必殺」だけ。スマホを横に倒せばそのまま迫力の横画面FPSとしてプレイできます！
